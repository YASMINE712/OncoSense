# Publication boundaries

This repository is a documentation-only portfolio showcase. It describes technical work completed in a restricted internship context while protecting the project material.

## Included

- High-level architecture and workflow diagrams
- A single curated, non-identifying learning-curve screenshot
- General descriptions of methods, tools, and engineering decisions
- Clear limits on what the artifact demonstrates

## Excluded

- Source code, notebooks, configurations, and internal reports
- Medical images, labels, annotations, metadata, or source datasets
- Model weights, optimizer states, logs, and raw predictions
- Proprietary documents, credentials, machine paths, and private infrastructure details

The content must not be interpreted as a runnable medical device, a clinical decision-support system, or a claim of clinical validation.
